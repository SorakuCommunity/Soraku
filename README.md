## ✨ About Soraku

Soraku bukan sekadar platform.  
Ini adalah **ruang digital tanpa batas** — tempat komunitas, kreator, dan identitas bertemu.

Terinspirasi dari budaya Jepang:
- 自由 (Kebebasan)
- 成長 (Pertumbuhan)
- 繋がり (Koneksi)

> Dari sekadar user → menjadi bagian dari ekosistem.
